HUMIS Homepage Project Reflection

The hardest part of this project was getting my Figma design to look almost exactly how I originally designed it. I had trouble with some of the responsive design, like making sure the font sizes changed when the screen got smaller or bigger. A lot of the time the page technically worked but there was way too much white space on big screens, so I had to figure out how to make the text and images bigger with media queries and give the page a height to have it stop stretching. Getting the dotted line on the News and Graduate Students pages to go all the way down like in the PDF also took a while because I didn't have my main and columns set to stretch to the bottom of the page. I also had trouble figuring out where exactly to put some of my changes because of the work we had already done in class. For example, in inner-styles.css I was adding onto the existing file and originally had my stuff at the bottom written out like main nav.sub-nav instead of nesting it like how we did in class, so it took me a while to refactor everything to match. I also ran into problems with browsers because I was using Safari and it wasn't showing the mobile view when I made the window small enough, so I kept adding more changes to fix it. When I switched to Chrome I saw it was actually working, so I went back and removed those changes.

The easiest part of this project was building the different parts of the pages because I have some prior experience, so making a new page with all the content on it was pretty easy. The mobile menu was also easier because I started it in a new file, so I knew where everything was instead of working around the class files. It was also easy to get things placed relatively where I wanted them.

I do feel like I understand the concepts introduced with the HUMIS project. I understand flexbox and was able to look up other flexbox properties like flex-shrink and flex-grow when I needed them, like for the news carousel and for making the columns stretch to the bottom of the page. This project was also a good review of CSS basics since I hadn't used it in a while. Responsive design was easier for me to understand and implement since I took a similar class in the CS department, so I already had experience using @media.

I'm actually already using some of what I learned here on my personal website. I think the biggest things I'll take with me are building mobile first, because I was taught responsive design but not designing for mobile first, keeping my CSS organized and nested from the start instead of fixing it at the end, and testing in Chrome or Firefox rather than Safari before I assume something is broken.
